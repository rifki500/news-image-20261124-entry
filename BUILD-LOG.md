## How the page was made

- Renderer: `render.py` (kept in the local build directory, not the repo)
  draws the page with Pillow 10.2.0 and DejaVu fonts: serif masthead,
  hero lead with a hand-drawn rising-chart pictogram, four leads with red
  top bars, "THE WORLD IN BRIEF" divider, 3×10 brief grid (red region
  label + bold headline + one-line summary), sources footer with the †
  legend.
- `main.py` (this repo, Python 3 standard library only) copies `entry.png`
  to `$MAKEFUN_OUTPUT_DIR` (default `/output`).
- Layout follows the 22–23 Nov v3 editions: 1024×1024, large type,
  hero lead, spacious legible layout. Headlines and summaries were
  shortened so each fits one line in its 306px column.
